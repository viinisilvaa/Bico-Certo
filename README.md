## 📖 Sobre o projeto

O **Bico Certo** é uma plataforma web desenvolvida como projeto acadêmico com o objetivo de aproximar profissionais autônomos e clientes que procuram serviços em sua região.

A ideia surgiu da necessidade de facilitar a divulgação de pequenos prestadores de serviços — como eletricistas, diaristas, pintores, manicures, encanadores e diversos outros profissionais — oferecendo uma plataforma intuitiva onde eles possam apresentar seus serviços e construir sua reputação por meio de avaliações dos clientes.

Além de aproximar clientes e profissionais, o projeto busca incentivar a economia local, tornando a contratação de serviços mais simples, rápida e confiável.

---

## 🎯 Objetivo

Desenvolver uma plataforma acessível que funcione como uma ponte entre quem oferece serviços e quem precisa contratá-los, proporcionando uma experiência prática, segura e eficiente para ambos.

### 👷 Para os profissionais

* Cadastro gratuito
* Perfil personalizado
* Divulgação de serviços
* Histórico de avaliações
* Maior visibilidade para novos clientes

### 🏠 Para os clientes

* Pesquisa por categorias de serviços
* Perfis completos dos profissionais
* Sistema de avaliações
* Contato facilitado com o prestador

## 🚀 Como executar o projeto

### Pré-requisitos

* XAMPP (Apache + MySQL)
* PHP 8 ou superior
* Navegador Web

### Instalação

Clone o repositório:

```bash
git clone https://github.com/viinisilvaa/Bico-Certo.git
```

Coloque o projeto na pasta **htdocs** do XAMPP.

Inicie os serviços **Apache** e **MySQL**.

Importe o banco de dados pelo **phpMyAdmin**.

Depois acesse:

```text
http://localhost/Bico-Certo
```
